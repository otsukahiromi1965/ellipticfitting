# EllipticFitting

楕円関数を用いた相関関数のフィッティングを行うC++プログラムです。
MPIで各サンプルの関数値と勾配を並列計算し、Levenberg–Marquardt法で
パラメータ `A`, `k`, `b` を求めます。対応する格子は `LCN=4`（正方格子）と
`LCN=6`（三角格子）です。
`main_acl` はフィッティングをせず、指定したパラメータから角度ごとの
相関長（ACL）を計算します。

## 必要な環境とビルド

- C++23対応のC++コンパイラ
- CMake 3.16以上
- Boostのヘッダー
- Eigen 3.3以上
- MPIのC++開発環境とランチャー（例: Open MPI）

依存ライブラリをインストールした環境で、リポジトリ直下から実行してください。

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
```

多倍長の楕円関数をコンパイルするため、ビルドには時間とメモリが必要です。
メモリ不足になる場合は `--parallel 1` を使用してください。

## フィッティング

```text
mpirun -np <プロセス数> ./build/main LCN datafile C_max C_min A k b
```

| 引数 | 意味 |
| --- | --- |
| `LCN` | 格子の配位数。`4` または `6` |
| `datafile` | 入力テキストファイルのパス |
| `C_max`, `C_min` | フィッティングに使う相関値の範囲。`0 < C_min < C_max < 1` |
| `A`, `k`, `b` | 初期パラメータ。すべて有限の数値で、`0 < k < 1` |

付属データを用いた実行例:

```sh
mpirun -np 2 ./build/main 6 Data/6/0/NX28_x20 5E-2 1E-2 1.0 0.567 1.0 > result.txt
```

入力はヘッダーなしの空白区切り4列です（空行は読み飛ばします）。

```text
i j correlation error
```

`i`, `j` は `0` 以上 `999` 以下の整数、相関値と誤差は有限の数値としてください。
入力の誤差はゼロでも構いませんが、負値は指定できません。
フィッティングに選ばれる点の誤差は、対称化後に正値である必要があります。
同じ座標が複数回現れた場合は最後の行を使用します。
正方領域の座標データを想定しており、欠けた座標はゼロとして扱われます。
対称化で参照する座標を含め、対象領域のデータを用意してください。
格子対称性に合わせて相関値と誤差を平均した後、
`C_min < correlation < C_max` を満たす `j >= 1` の点をフィッティングに使用します。
少なくとも3点が必要です。現在は各方向1000点の固定配列を使用するため、
範囲外の座標インデックスはエラーになります。

出力は標準出力に書き出されます。

- `begin{loop}`: 反復番号、`A`, `k`, `b`, 平均二乗正規化残差 `X`、減衰係数 `Lambda`
- `begin{disp_deviation_...}`: 座標、入力相関値、フィット値、相対偏差
- `begin{disp_ACL}`: パラメータと、角度（ラジアン）、求根した `v`、関数残差の絶対値、相関長

最大反復回数は100、相対改善量の閾値は `1e-6` です。
初期値によっては収束しない場合や楕円関数・ACLの求根が失敗する場合があります。
更新後の `k` が範囲外になるとエラー終了します。初期値やフィッティング範囲を調整してください。

補助スクリプト `go0.sh` も利用できます。入力と出力のパスは省略可能です。

```sh
./go0.sh path/to/input.txt path/to/result.txt
```

このスクリプトはホストファイル `MPI_Local_Host` を使用し、`LCN=6` と
固定のフィッティングパラメータでMPIジョブをバックグラウンド実行します。
使用前に、ホスト構成とフィッティング条件に合わせてスクリプトを編集してください。

## ACLだけを計算する

```sh
./build/main_acl 6 0.567 1.0
```

引数は `LCN k b` です。ACL計算では振幅 `A` を使用しません。
両方の実行ファイルで `--help` を指定すると使い方を表示します。

ローカルのホストファイルは、公開前に別途確認してください。

本リポジトリには現時点でライセンスを設定していません。
再利用・再配布の条件は、コードとデータの権利者が決定したうえで明記してください。
